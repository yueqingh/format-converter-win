格式转换 v1.0.0（Windows 10 / 11，64 位）
========================================

【怎么用】
1. 双击 FormatConverter.exe。
2. 把视频/音频文件拖进窗口（或点“添加文件”“添加文件夹”）。
3. 右侧选“转换成”什么格式，点“开始转换”。
   结果默认保存在原文件旁边的“转换结果”文件夹，不会覆盖原文件。

【常用功能】
- 预设：“语音识别专用”就是 16kHz 单声道 16 位 WAV。
- 高级设置：采样率、声道（可只取左/右声道）、位深、码率、音量、画面大小、帧率、编码、字幕、
  按目标大小压缩、剪切（在文件行点“设置”）。
- 试转前 30 秒：先试一小段看效果，再决定要不要转完整文件（旧电脑很省时间）。
- 合并：勾选“合并成一个文件”，用 ↑ ↓ 调整顺序。
- 文字 · 语音识别 TXT：先点右上角“设置”，选好你已经部署的 SenseVoice 程序、模型、VAD 文件。
- 字幕 · 提取内嵌 SRT：把视频里的文字字幕导出成 .srt 文件。
- 每个文件可以点“设置”单独设参数。

【遇到问题】
点右上角橙色的“复制诊断报告”，然后把内容粘贴发给开发者。
程序旁边的 data 文件夹里有日志（app.log）和配置（config.json），删除 config.json 可恢复默认设置。

【Windows 提示“已保护你的电脑”？】
这个程序没有购买代码签名证书，第一次运行时 Windows 可能提示。点“更多信息”→“仍要运行”即可。
若被杀毒软件隔离，请把 FormatConverter 文件夹加入信任。

【卸载】
直接删除整个 FormatConverter 文件夹。
